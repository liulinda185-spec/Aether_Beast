# 垂直切片规格 v0.2　·　霜原一局

> 2026-11-15　|　状态：规格已定，代码未开始
> 目标不是"做出游戏"，是**证明按下去有反馈、且能复现**。这一份验收通过后，界面才值得做。

---

## 1　范围（就这么多，多的不做）

| 项 | 值 |
|---|---|
| 世界 | 1 个，生境固定**霜原**，种子可指定（默认 `20261111`） |
| 世界兽 | 8 只（由 `worldgen.py` 出，不手工写） |
| 玩家 | 1 只神兽，**3 个素材槽**（已定），装 min(4, 方向数) 个能力 |
| 时长 | 16 刻 |
| 死法 | 沿用 GDD §6.1 的三条：混沌终焉 / 文明崩塌 / 灰烬 |
| 界面 | Canvas 2D 俯视，最小可视（能点、能看数、能看死法） |

## 2　16 刻怎么分

| 刻 | 类型 | 玩家能做什么 |
|---|---|---|
| 2,4,6,8,10,12,14,16 | **遭遇刻** | 面对一只兽 + 它的钩子，选 3 个选项之一（六维变动） |
| 1,3,5,7,9,11,13,15 | **自由刻** | 三选一：**移动**一格 / **观察**一只兽（掉素材）/ 用**轻档**能力微调 |

- 观察一只兽 = 1 个自由刻，所以"全观察 8 只"等于放弃移动与微调（算术上不可能两全）。
- 轻档能力不占刻，每局 3 次；中档占 1 刻；重档占 1 刻且**混沌 +2**。
- 神兽能力选"自己"为作用域时，效果记在**善恶**上，不改六维。

## 3　数值（照抄 GDD，不在这里重新发明）

```
μ  = 六维均值
σ  = 总体标准差（除以 6）
均衡度 Balance = clamp(100 − 2.5·σ, 0, 100)

失衡项   = max(0, (100 − Balance) / 15)
衰退项   = max(0, (50 − μ) / 15)
议题压力 = p（开局 1.0；未处置 +0.3/刻，处置 −1.2/刻，上限 3.0）
混沌基数 = 失衡项 + 衰退项 + 议题压力
混沌增长 = 混沌基数 × (1 + Chaos/100)^2.0
```

死法判定（优先级从上到下）：

1. **混沌终焉**：Chaos ≥ 100
2. **文明崩塌**：Balance < 28 连续 6 刻（回升则倒计时 −1）
3. **灰烬**：μ < 20 连续 6 刻

善恶漂移（已锁定的第 2 项决策）：每刻结算后若 |善 − 恶| ≥ 25，六维按方向漂移 δ = 0.6；善占优 → 环境 / 平等 ↑、繁荣 / 自由 ↓，恶占优反向。

## 4　素材掉落

观察 → 掉落，走 `tools/beastgen/drops.py` 的两级过滤：**先按骨架筛形态，再要求元素对得上**；都对不上才退回"仅元素"。

已知比例：800 次掉落里 42% 严格匹配、58% 仅元素（素材库 20 件 / 36 格）。切片阶段接受这个比例，且**必须在掉落提示里写清是从哪只兽身上取的**，否则玩家会觉得素材凭空冒出来。

## 5　验收标准（六条，全部可脚本判定）

| # | 标准 | 判定方式 |
|---|---|---|
| A1 | **同种子必同局** | 同种子跑两次，逐刻六维 / 混沌序列完全一致（浮点按 1e-9 比较） |
| A2 | **与配平表读数一致** | GDD §3.2 的四个世界样本（全50 / 失衡独裁 / 失序繁荣 / 全10），第 1 刻 Balance 与 `02平衡值` 一致，误差 ≤ 0.1 |
| A3 | **三种死法可触发** | 三条构造轨迹分别触达 Chaos≥100、Balance<28 连 6、μ<20 连 6，且不会误触发其它两种 |
| A4 | **能力全部合法** | 144 形状可实例化；每条恰好一升一降；量级 3–9（`beastgen.py` 已有断言，切片里再跑一次） |
| A5 | **素材可达** | 20/20 件能从某个世界采到（`drops.py` 已过，切片里换成"从霜原 8 只兽能采到 N 件"并给出数字） |
| A6 | **存活率同档** | 200 局 × 4 打法（均衡 / 取舍 / 只看均衡度 / 乱选），存活率与 `final_calc.py` 同档，偏差 ≤ 3 个百分点 |

A6 是这六条里最容易被糊弄的一条：**如果切片跑出来的存活率明显高于配平表，说明神兽能力把游戏变简单了，不是"引擎实现得对"**。

## 8　已知风险（写下来，免得做的时候才发现）

1. **神兽能力可能把游戏变简单**：144 形状里有 8 组方向 × 6 作用域，量级封顶 9 与事件卡同档，但玩家一局能用 8 次中/重 + 3 次轻，合计影响力可能超过 8 张卡。A6 就是查这个的，若超标，先降"轻档每局 3 次"或把重档混沌 +2 提到 +3，**不动数值阶梯**。
2. **窄兽的可读性**：构筑界面必须直接显示"当前方向数 / 可装槽位"，否则玩家打完一局才发现只有两个按钮。
3. **58% 掉落只能按元素**：切片必须把掉落来源写在提示里，否则显得随机。
4. **轻档经济未实测**："每局 3 次不占刻"是拍的，A6 跑完才知道够不够。
